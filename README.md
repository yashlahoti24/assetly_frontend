# Assetly Frontend

Assetly Frontend is the user interface for **Assetly**, a portfolio and budget management platform. It allows users to visualize their investments, track budgets, and gain insights through interactive charts.

## 🛠 Tech Stack
- HTML5  
- CSS3  
- JavaScript (ES6)  
- Bootstrap 5  
- Chart.js  

## ✨ Features
- 📊 **Portfolio Overview** – Track all investments in one place  
- 📈 **Interactive Charts** – Visualize financial data with Chart.js  
- 📱 **Responsive Design** – Fully responsive using Bootstrap  
- 💰 **Budget Tracking** – Display and monitor monthly budget limits  
- 🎨 **Custom UI** – Styled with Bootstrap and custom CSS
